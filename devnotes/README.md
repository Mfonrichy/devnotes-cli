# DevNotes CLI 🧠

A lightweight command-line tool for developers to quickly store, search, and manage notes/snippets.

## ✨ Features

- Add notes with tags
- Search notes instantly
- Delete notes
- Persistent local storage (~/.devnotes)

## 🚀 Installation

```bash
pip install -e .
```

## 🧠 Design Decisions
- JSON storage for simplicity and portability
- CLI-first design for developer workflow
- Modular architecture for easy extension

## 🚧 Future Improvements
- Fuzzy search
- Rich CLI formatting
- Sync with cloud storage
- Export to Markdown
